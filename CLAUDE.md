# Project Conventions

## Language

- All code (identifiers, comments, strings, logs) MUST be written in English.
- All Markdown documentation (`.md` files) MUST be written in English.
- This applies regardless of the language used in conversation.

## Emojis

- Never use emojis in code, comments, commit messages, or Markdown files.
- Do not add emojis to UI copy, logs, or output unless the user explicitly requests them.
