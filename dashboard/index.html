Quick start

Run each module in its own terminal. The dashboard pings each port to show live status above.

Veteran Capture

localhost:8001
# from repo root
cd veteran-capture
uv run python -m veteran_capture.cli serve

Driver Briefing

localhost:8080
# from repo root
export ANTHROPIC_API_KEY="sk-..."
uv run python main.py

Warehouse 3D

localhost:8000
# ES modules + fetch need HTTP, not file://
cd app/frontend
python3 -m http.server 8000
